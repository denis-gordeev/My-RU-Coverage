# Обновление обогащения

Повторное исследование и обновление разделов обогащения (Описание деятельности, Положение в цепочке поставок, Ключевые клиенты и поставщики) для существующих отчётов. Финансовые таблицы сохраняются.

## Использование

- `/обновить-обогащение SBER` — один тикер
- `/обновить-обогащение SBER YDEX OZON` — несколько тикеров
- `/обновить-обогащение --сектор Финансовые услуги` — весь сектор
- `/обновить-обогащение` — все тикеры (запросит подтверждение)

## Инструкции

### Шаг 1: Определение целей

Определите область действия из сообщения пользователя. Если область — «все» или очень большая (>50 тикеров), запросите подтверждение.

### Шаг 2: Исследование

Для каждого тикера:
1. Прочитайте текущий файл, чтобы понять существующее содержимое
2. Веб-поиск: `[Тикер] инвесторские отношения годовой отчёт`, `[Тикер] годовая отчёт`, `[Компания] инвестиционная презентация основные клиенты`
3. **ПРОВЕРКА**: название компании в файле совпадает с исследованием (Золотое правило #2)
4. Подготовьте обогащение:
   - `описание`: Описание деятельности на русском языке с [[викилинками]] для компаний, технологий и материалов
   - `цепочка_поставок`: Структурированная цепочка поставок (верхний контур / ключевое звено / конечный спрос) с конкретными названиями
   - `клиенты_и_поставщики`: Ключевые клиенты и поставщики с конкретными названиями

### Шаг 3: Применение

Запишите данные обогащения в JSON-файл, затем запустите:

```bash
python scripts/update_enrichment.py --данные enrichment.json [область]
```

Опции области: `SBER`, `SBER YDEX`, `--сектор Финансовые услуги`, или пропустите для всех записей в JSON.

### Шаг 4: Аудит

```bash
python scripts/audit_ru_reports.py
```

Проверьте, что все цели проходят (10+ викилинков, нет обобщений, нет секций-заглушек, нет английского).

### Правила качества (из CLAUDE.md)

- Каждый [[викилинк]] — конкретное имя собственное
- Минимум 10 викилинков на файл
- Технологические и материальные викилинки равнозначны: `[[Астра Линукс]]`, `[[152-ФЗ]]`, `[[ФСТЭК]]`, `[[карбид кремния]]`
- НЕТ общих слов в скобках: поставщик, клиент, компания, предприятие
- Всё содержимое на русском языке
- Цепочка поставок разделена по категориям, не однострочными заметками
