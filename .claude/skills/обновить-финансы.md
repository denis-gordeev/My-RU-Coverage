# Обновление финансовых данных

Обновляет секцию `## Финансовый обзор` в отчётах тикеров последними финансовыми данными из yfinance. Также обновляет рыночную капитализацию и стоимость предприятия в метаданных.

**Всё содержимое обогащения (Описание деятельности, Положение в цепочке поставок, Ключевые клиенты и поставщики) сохраняется — заменяются только финансовые данные.**

## Использование

Пользователь может указать область действия в сообщении:

- **Все тикеры**: `/обновить-финансы` (без аргументов — обновляет все отчёты)
- **Один тикер**: `/обновить-финансы SBER`
- **Несколько тикеров**: `/обновить-финансы SBER YDEX OZON`
- **По сектору**: `/обновить-финансы --сектор Финансовые услуги`
- **Пробный запуск**: добавьте `--пробный-запуск` для предпросмотра без записи

## Инструкции

1. Разберите аргументы пользователя из сообщения.
2. Запустите скрипт обновления:

```bash
python scripts/update_financials.py [АРГУМЕНТЫ]
```

3. Сообщите результаты: сколько обновлено, пропущено, с ошибками.
4. При обновлении ВСЕХ тикеров предупредите пользователя о времени выполнения (~15-30 мин для ~60 тикеров из-за ограничений yfinance) и запросите подтверждение.
5. После завершения спросите, хочет ли пользователь зафиксировать изменения.

## Что обновляется

| Поле | Источник | Расположение |
|---|---|---|
| **Рыночная капитализация** | `акция.info['marketCap']` | Блок метаданных |
| **Стоимость предприятия (EV)** | `акция.info['enterpriseValue']` | Блок метаданных |
| **Годовые данные (3 года)** | `акция.income_stmt` + `акция.cashflow` | Таблица `### Ключевые финансовые показатели по годам (3 года)` |
| **Квартальные данные (4 кв.)** | `акция.quarterly_income_stmt` + `акция.quarterly_cashflow` | Таблица `### Ключевые финансовые показатели по кварталам (4 квартала)` |

Все денежные значения в **млн руб.** (для тикеров `.ME`). Маржа в **%**.

## Отслеживаемые метрики

Выручка, Валовая прибыль, Валовая маржа %, Коммерческие расходы, Управленческие расходы, Операционная прибыль, Операционная маржа %, Чистая прибыль, Чистая маржа %, Операционный денежный поток, Инвестиционный денежный поток, Финансовый денежный поток, Капитальные затраты.
